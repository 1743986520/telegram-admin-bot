除了普通文字，也處理 caption、聯絡人分享與媒體 fingerprint；10 分鐘內同內容 3 次可視為洗版。

Detection pipeline

偵測不是單一分數，而是一條分層流程

高置信規則優先；模糊案例再進相似度、語境保護與帳號畫像。已知誤判則由白樣本反向救援。

01 / CLEAN

文字正規化

零寬字元、NFKC、拆字、形近/同音混淆與數字字母替代。

02 / L1

166 條規則

明確話術命中直接給出規則原因與置信度。

03 / L2

269+ 模板

TF-IDF 雙向量器處理改寫，並依文字長度調整門檻。

04 / GUARD

語境與白樣本

品牌、付款詞避免裸詞誤封；白樣本可救回已知正常說法。

05 / PROFILE

帳號畫像

只有邊界或中性話術需要時，才額外讀取發送者 profile 訊號。

純圖片內容目前不做 OCR；沒有 caption 的圖片/影片/文件主要透過 Telegram 的 file_unique_id 參與重複洗版判斷。
Operations

管理、測試、樣本維護都在 Telegram 裡完成

常用動作不必改檔案；樣本新增、白名單、去重與模板熱更新都能從 Bot 內操作。

/settings群組管理員查看 14 個群組功能開關，並透過按鈕切換。
/test · /stop所有人逐則測試判定結果，不實際刪除或禁言。
/guard · /omg群組管理員啟動炸群應急防護；/stop 後決定如何處理期間加入者。
/addsampleBot Owner把新廣告加入動態樣本庫，正規化去重後立即生效。
/whitelistBot Owner把誤封加入白樣本；回覆用法會嘗試解除該使用者禁言。
/samples [wl]Bot Owner檢視動態廣告/白樣本並直接按鈕刪除。
/exportsamples本群管理員匯出廣告樣本與白樣本 JSON。
/cleanupads本群管理員與官方模板做正規化去重後熱重載。
/updateadBot Ownergit pull 後熱重載廣告模板，不重啟整個 Bot。
/updateBot Owner拉取完整更新並重新啟動程序。
/ban · /banme管理 / 彩蛋管理員禁言指定成員；一般成員可自願禁言 2 分鐘。
/vote · /propose群組管理員全員禁言公投與自訂提案流程。

Emergency mode

/omg：真的出事時，先把入口關起來

防護模式不走一般歡迎或驗證流程。新加入者直接靜默限制，入群系統訊息自動刪除，成員名單另外記錄。

解除後可以「全部踢出 / 挑選踢出 / 不踢出」。這讓大規模惡意入群和日常廣告偵測保持兩條不同的處理路徑。

admin@group $ /omg

🛡 防護模式已啟動
• 新加入成員 → 完全限制
• 歡迎 / 驗證 → 暫停
• Join service message → delete
• Joined list → persisted

admin@group $ /stop
✓ 選擇：全部踢出 / 挑選 / 保留
